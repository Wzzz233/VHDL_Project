# 项目进度与需求对照

## 项目概述

**赛题**: 第十届集创赛"紫光同创"企业命题 —— 基于紫光同创FPGA的智能交通感知系统

**硬件平台**: RK3568MES2L50H (PG2L50H FPGA + RK3568 ARM)

**数据通路**: OV5640摄像头 → FPGA(DDR3帧缓存) → PCIe DMA → RK3568 → HDMI显示/AI推理

**开发周期**: 2026-02-12 ~ 2026-03-01 (共78次提交)

---

## 已完成工作详细清单

### FPGA侧 (hdl/)

**PCIe DMA子系统** — 核心数据通路, 已完成并经过大量调试:
- `pcie_dma_cam_top.v` — 顶层集成模块
- `pcie_dma_ctrl/ips2l_pcie_dma_controller.v` — DMA主控制器
- `pcie_dma_ctrl/ips2l_pcie_dma.v` — DMA顶层封装
- `pcie_dma_ctrl/ips2l_pcie_dma_tx_top.v` — TLP发送顶层
- `pcie_dma_ctrl/ips2l_pcie_dma_rx_top.v` — TLP接收顶层
- `pcie_dma_ctrl/ips2l_pcie_dma_mwr_tx_ctrl.v` — Memory Write发送
- `pcie_dma_ctrl/ips2l_pcie_dma_mrd_tx_ctrl.v` — Memory Read发送
- `pcie_dma_ctrl/ips2l_pcie_dma_cpld_tx_ctrl.v` — Completion发送
- `pcie_dma_ctrl/ips2l_pcie_dma_tlp_rcv.v` — TLP接收解析
- `pcie_dma_ctrl/ips2l_pcie_dma_rx_cpld_wr_ctrl.v` — Completion写控制
- `pcie_dma_ctrl/ips2l_pcie_dma_rx_mwr_wr_ctrl.v` — MWR写控制
- `pcie_dma_ctrl/ips2l_pcie_dma_tx_mwr_rd_ctrl.v` — MWR读控制
- `pcie_dma_ctrl/ips2l_pcie_dma_tx_cpld_rd_ctrl.v` — CplD读控制
- `pcie_dma_ctrl/ips2l_pcie_dma_rd_ctrl.v` — DMA读控制
- `pcie_dma_ctrl/ips2l_pcie_dma_wr_ctrl.v` — DMA写控制
- `pcie_dma_ctrl/ips2l_pcie_dma_tlp_tx_mux.v` — TLP发送仲裁
- `pcie_dma_ctrl/ips2l_expd_apb_mux.v` — APB总线复用

**DDR3读写控制** — AXI接口封装:
- `wr_rd_ctrl_top.v` — 读写控制顶层
- `wr_cmd_trans.v` — 写命令翻译(长传输→16拍burst)
- `wr_ctrl.v` — AXI写通道控制
- `rd_ctrl.v` — AXI读通道控制

**摄像头子系统** — OV5640采集:
- `power_on_delay.v` — 上电时序(5ms+1.3ms+21ms)
- `i2c_com.v` — I2C位操作通信
- `iic_dri.v` — I2C主控制器(400kHz, 支持1/2字节地址)

### RK3568 Linux侧 (ARM/)

**内核驱动**:
- `pcie_fpga_dma.c` — PCIe DMA内核模块(BAR映射, DMA传输, 字符设备)
- `pcie_fpga_dma.h` — 驱动头文件(IOCTL定义, 寄存器偏移)
- `Makefile` — 内核模块+应用编译

**用户态应用**:
- `fpga_dma_test.c` — DMA测试工具(设备信息/帧采集/PPM导出)
- `fpga_hdmi_display.c` — HDMI显示(GStreamer appsrc→kmssink)
- `fpga_lpr_display.c` — 车牌识别显示(RKNN推理+结果叠加)

**诊断工具**:
- `analyze_frame_diff.py` — 帧间差异/延迟检测
- `audit_reg_config.py` — OV5640寄存器配置审计
- `analyze_ppm_metrics.py` — 图像质量分析
- `run_hdmi_kms.sh` / `run_lpr_kms.sh` — 启动脚本

### 阶段2: HDMI显示与LPR应用 (02-14 ~ 02-15)
- KMS HDMI显示应用(BGR565→BGRx转换)
- GStreamer低延迟管线优化(leaky queue)
- RKNN车牌识别应用框架
- 摄像头时钟域重构(cmos_8_16bit纯RTL替换)
- 诊断工具集(帧差异分析, 寄存器审计)

### 阶段3: 摄像头采集稳定化 (02-22 ~ 02-26)
- OV5640采集边沿选择(posedge/negedge验证)
- 单cmos1_pclk时钟域重构
- 字节配对加固, 行有效/像素有效语义分离
- 黑屏/条纹回归修复
- 测试图案注入(color-bar, test pattern)
- MWR读数据流水线寄存器修复(消除竖条纹)

### 阶段4: DMA流控与帧模式 (02-26 ~ 03-01)
- Zero-copy BGRX管线(mmap直接显示)
- 帧模式MSI中断DMA路径

- 1024DW chunk编码统一
- 帧就绪背压机制
